cc-calsync privacy policy

Last updated September 28, 2026.

What it reads

Through the Google Calendar API, it reads the events on its owner's own calendars to find their start and end times. It does not keep event titles or descriptions.

What it writes

Busy blocks on those same calendars, labelled only "Busy" or "Out of office". Nothing from the original event is copied: not its title, description, place or guests. When the original event moves or is deleted, the block moves or is deleted too.

What it stores

The sign-in tokens with the email address of each calendar account, and a log of how many blocks each run created, moved or deleted. Both sit on a private server the owner controls.

Sharing

Nothing is sold, shared or sent to anyone. The data is used only to keep the owner's calendars in sync.

Google user data

cc-calsync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions. The tool's remove-all command deletes every block it created.
